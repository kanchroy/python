Bitwise operators - 
1. Conjunction [&] - this operator will produce a 1 if both bits are 1. Or its returns 0. 
2. Disjunction [|] - this operator will produce a 1 if either both bits are 1 or atleast 1 bit is 1. 
3. Exclusive [^] - this operator will produce a 1 if only one of the bit are 1, if both bits are 1 or 0,    it will return 0. 
4. Negation [~] - this operator will produce a 1 for every 0 and 0 for every one. 

Bit-shifting: 
Bit Shift Right - >> AND Bit Shift Left - <<
